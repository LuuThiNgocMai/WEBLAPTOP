# kiem-thu-web-laptop-selenium
Kiểm thử tự động website bán laptop sử dụng Selenium

# Giới thiệu
Dự án thực hiện kiểm thử tự động cho website bán laptop sử dụng:
- Selenium WebDriver
  
# Cách chạy project
1. Clone project
2. Mở bằng Visual Studio 2022
3. Cài đặt package cần thiết (nếu thiếu)
4. Run test
